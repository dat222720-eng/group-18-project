# Vai trò: Nam — Frontend (React + Axios)

## Nhánh làm việc
- frontend

## Nhiệm vụ
- Khởi tạo CRA, cấu hình "proxy": "http://localhost:3000"
- Components: AddUser.jsx, UserList.jsx
- Gọi API /users (GET/POST/PUT/DELETE) bằng axios
- Validate form (name không trống, email hợp lệ)

## Cách chạy
cd frontend
npm install
npm start
